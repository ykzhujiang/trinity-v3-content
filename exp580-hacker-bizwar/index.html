黑客×商战 · 第一章

逆向人生

代码气味
「有人偷了我的代码。
更讽刺的是——
我是最后一个知道的人。」
向下滑动开始阅读

深夜办公室

凌晨两点半。整栋楼就剩我和保安。
保安比我先下班。
海外DAU连跌三天。我盯着曲线，曲线盯着我。
谁先眨眼谁输。
陈磊：「老大你看这个」配了一个链接。
凌晨两点半发消息的CTO，要么是bug，要么是噩耗。
我点开看了三秒。然后关掉。
又打开。又看了三秒。
然后把手机扣在桌上。
界面布局一样。交互逻辑一样。
甚至那个我亲手设计的、"左滑生成右滑发布"的手势——一模一样。

这不是"借鉴"。这是Ctrl+C Ctrl+V。
我深吸一口气。创业七年，抄袭见得多了。
但抄到这个程度——要么对方有个天才产品经理，要么……
要么他们有我的源码。

大学那会儿我能花一个通宵逆向一个加密狗。
现在——我只需要一台电脑和一杯咖啡。

逆向分析

十年没碰逆向工具了。
手指放上键盘的那一瞬间——肌肉记忆比大脑先反应过来。
发现竞品几乎完全抄袭，我的第一反应是——
A.报警 + 请知识产权律师
B.先别声张。自己动手逆向分析竞品，搞清楚到底怎么回事
C.叫陈磊带安全团队排查
APK拉下来。jadx反编译。smali代码像瀑布一样往下滚——
这种感觉，像老司机重新坐上驾驶座。
等等。这段注释……
// TODO: 老王说这里要改 —— 0312

"老王"？我们公司没人叫老王。但是——我们的代码规范里，TODO注释的格式和这个一模一样。
不是抄袭。是偷。

有人把我们的代码原封不动拿走了，只来得及改变量名，连注释都没删干净。
代码是从内部流出去的。
这意味着——我的团队里有内鬼。
跟我朝夕相处的人，背后捅了我一刀。
凌晨四点。我又回到了那个熟悉的状态——
一个人，一台电脑，一个要被我拆开看的系统。

只不过这次要拆的，是我自己的公司。

伪装日常

早上九点。我洗了脸，换了衣服，笑着跟每个人说早安。

没有人知道我已经醒了整整24小时，也没有人知道——我在观察他们每一个人。
晨会照开。我汇报DAU下滑，"可能是算法需要调优"。
没提FlashClip。没提代码泄露。

我要看看——谁的表情不自然。
后端的小李在看手机。这不稀奇，他一直看手机。
但今天他锁屏的速度……快了零点五秒。

也许是我多想了。
但黑客教过我一件事——异常就是线索，哪怕它只有零点五秒。
"磊子，昨晚那个链接你怎么发现的？"
我语气很随意，就像聊天。
但我的耳朵竖起来了。
"Reddit上有人发的。说这个App跟我们像双胞胎。"

他的眼神没闪。
要么他清白，要么演技比我好。

设陷阱

能接触到核心代码的人，不超过八个。
我在白板上画出每个人的代码权限范围。

这是一道排列组合题——我大学最擅长的。
已确认是内鬼。八个嫌疑人。我的下一步——
A.开全员大会当面质问，以气势压人
B.悄悄在每个人的代码权限里埋不同的"水印陷阱"，等内鬼自投罗网
C.直接查服务器access log和监控录像
八个人，八个不同的水印。
每个人的代码分支里，我会悄悄插入一段无害但独特的注释。

谁的水印出现在FlashClip的下一次更新里——谁就是内鬼。
晚上十一点。老婆以为我在加班。
某种意义上——没错。

只不过这份"加班"的内容，比公司任何一个项目都刺激。
水印1号——在推荐算法的冷启动模块里，加了一行
// perf: entropy_seed=42

小李负责这块。如果42出现在FlashClip里——gotcha。
水印2号：数据管道。老张的地盘。
// sync_v2_hotfix_0315
水印3号：视频渲染。阿伟的领地。
// render_cache_flag=bravo
水印4号：用户系统。小周管的。
// auth_compat_legacy_mode
陷阱布好了。
现在，等。

投资人危机

赵薇薇的电话。VC合伙人。我们B轮的领投。

接到她的电话从来不是好事——因为好消息她发微信，坏消息她才打电话。
"朱江，市场上出了一个叫FlashClip的东西。你知道吗？"

她的语气很平，平得我背后发凉。
VC的平静等于暴风雨前的沉默。
投资人问起FlashClip，我选择——
A.坦白说"我们发现有内鬼在调查"
B."竞品只是皮相像，我们的核心壁垒——算法和数据飞轮——他们抄不走"
C."我正在处理，三天后给你详细报告"
我跟她聊了十五分钟。核心壁垒、数据飞轮、算法迭代——每一句都是真的，只不过省略了"有人偷了我们代码"这个小细节。

创业者最重要的技能不是融资，是在危机时让所有人觉得你很稳。
挂了电话，邮箱里多了一封。
发件人——匿名。

标题只有四个字：「别查了。」

对手比想象的更大

我盯着这四个字。笑了。

你知道对一个黑客说"别查了"意味着什么吗？
意味着——你承认了有东西值得查。
回公司。我没去自己办公室，直接进了服务器机房。
匿名邮件的邮件头信息告诉我——它是从我们公司内网发出去的。

不是从外面发来的。
内鬼不仅偷代码——他还在监视我。他知道我在查。
网络日志像一条河。大多数数据包是正常的——API调用、数据库查询、员工上网摸鱼。

但有一条细流，定时向一个境外IP发送加密数据包。每隔6小时一次。精确到秒。
六小时一次，定时精确到秒。
这不是人在手动操作——这是一个自动化程序。

有人在我们的服务器上埋了一个后门。
持续、安静、精确地把数据往外抽。
很专业。
但再专业——也怕碰上我这种人。

猎物锁定

反向追踪跑了四十分钟。
数据包经过三层跳板——新加坡、法兰克福、香港。

最终落点在——
深圳。南山区。
距离我的办公室——
直线距离1.3公里。
1.3公里。
我每天上班路过的那些写字楼里，有一栋楼，有一间办公室，有一个人——
正在用我的代码赚我的钱。
我给陈磊发了一条消息：
"明天请假一天。别问为什么。"
创业七年，我一直告诉自己——我是一个商人。

今天我发现，我骗了自己七年。
骨子里，我一直是那个
凌晨在宿舍里拆加密狗的少年。

只不过这一次——
要拆的不是软件。
是人心。
第一章完
