凌晨两点，三线城市城中村的一间出租屋。

陈小北坐在廉价塑料椅上，手机屏幕的冷光打在他的脸上。电商店铺因为刷单被平台封了。12万货款，冻结。

景别：极端特写 / 手机屏幕

账户余额：83.5元。

这够干什么？半个月的泡面钱。

景别：中景 / 出租屋 / 昏暗灯光

手机震动。女朋友的消息——

你连自己都养不活。

简短，干脆，没有一句废话。就像法院判决书。

景别：特写 / 手机屏幕 / 科幻
📢 恭喜！直播之王系统已激活。
您的起始等级：素人（粉丝：0）
系统AI助手"流量"已上线。

……我手机中毒了？

景别：俯拍全景 / 出租屋 / 科幻光效

它在空中浮着，像个骄傲的播放按钮。

· · ·
景别：中近景 / 出租屋 / 全息光

陈小北往后一仰，差点从椅子上摔下去。

你、你什么东西？！

景别：过肩镜头 / 陈小北看流量

"流量"上下打量了他一圈，语气充满了嫌弃——

就这？你确定你不是系统随机分配的测试用户？

陈小北："……"

我这颜值能直播吗？

颜值？你以为直播拼的是颜值？丑人才有辨识度。恭喜你，你赢在了起跑线。

景别：极端特写 / 面部 / 半明半暗

陈小北嘴角抽搐了一下。被一个三角形吐槽长相，这种体验他以前还真没有过。

行吧，反正也不能更惨了。

景别：全身 / 浴室 / 镜像构图

"流量"教他第一个技能——镜头感 Lv.1。

简单来说，就是能本能地感知摄像头的最佳角度。像是在你脸上装了个隐形罗盘，永远指向"好看那边"。

虽然你那张脸怎么转都差不多，但好歹有个进步方向。

· · ·
景别：特写 / 全息界面 / 红色警告
🎯 新手任务
在24小时内获得100个真实粉丝
⏰ 倒计时：24:00:00
✅ 奖励：口才Lv.1 + 500流量点
❌ 失败：热度值-50，限流3天

我连开播都不敢，你让我24小时100粉？

别废话。你现在是0粉。0到100比你想的容易。从100到1000才是地狱。

景别：中景 / 出租屋 / 暖色灯光

陈小北用几本书摞了个"手机支架"，把唯一一盏台灯掰成补光灯的角度，对着镜头深呼吸了三次。

就当……就当在跟空气说话。

景别：手机镜头POV / 自拍视角

画面里的陈小北试图微笑，但那表情——

像是便秘第三天终于进了厕所的人。

大、大家好……我是……呃……

景别：分屏 / 直播界面 / 数据

在线人数：1

那是他自己的小号。

说话！你是直播不是默剧！

我、我说什么？

说你为什么穷！穷人的故事最吸引穷人！

景别：侧面中景 / 动态 / 暖+冷光

陈小北被激怒了。

他不再紧张，开始疯狂吐槽自己的创业失败——进了一万双"智能加热拖鞋"，结果三月份气温突然飙到30度，一双没卖出去。为了清库存去刷单，被平台抓了个正着。

他说得太真实、太狠毒了。就像一个人站在楼顶往下看，反而获得了一种疯狂的自由。

景别：特写 / 手机屏幕 / 数据跳动

弹幕突然开始刷屏——

「哈哈哈哈哈哈」「智能加热拖鞋是什么鬼」「这哥们是真惨还是在演的」「笑死我了关注了」

在线人数：1 → 50 → 200

· · ·
景别：全景 / 出租屋 / 全息弹幕

他的"智能加热拖鞋"段子被人录屏发到了群里。人越来越多。但画风开始不对——

「可怜」「这种人也配直播？」「电商都做不好还想当主播？」「下播吧兄弟别丢人了」

景别：极端特写 / 眼睛 / 屏幕反光

那些字像针一样扎进来。

他们说得……也没错。电商做不好的人，凭什么做直播？

"流量"的声音冷不丁冒出来——

检测到负面流量。是否激活"控场Lv.1"预览？

景别：中景 / AR可视化 / 多色光

他眼前的弹幕突然变了。每一条弹幕都带上了颜色——

🔴 红色 = 愤怒/恶意
🔵 蓝色 = 无聊/路过
🟢 绿色 = 好奇/潜在粉丝

原来骂他最狠的那几个，全是红色。而默默看着没说话的大多数，是绿色。

让那些喷你的人，变成你的粉丝。

景别：近景 / 动态 / 自信姿态

陈小北对着镜头，嘴角微微上扬。

说我可怜的那位——你凌晨三点看我直播，你是不是也睡不着？

弹幕安静了一秒。

景别：手机镜头POV / 直视观众

说我不配的那位——你头像是保时捷，备注是"月薪8000"。你我……半斤八两啊兄弟。

「哈哈哈哈开大了」「保时捷那个人呢？跑了吧」「这哥们有点东西啊」「关注了关注了！」

景别：俯拍全景 / 绿色弹幕 / 氛围转暖

评论区风向逆转。红色弹幕一条条变绿。

在线人数：80+

原来把黑粉变成粉丝的诀窍不是证明他错了——而是证明你们是一样的。

· · ·
场景切换：MCN公司 / 高端办公室 / 冷色调

与此同时。某MCN公司，34楼，全玻璃幕墙。

一个穿定制西装的星探，在数据监控屏上注意到了一个异常——一个0粉素人，在线人数30分钟内从1冲到了200。

景别：特写 / 手机 / 私信界面

陈小北下播后看到一条私信——

「你好，我是星辰MCN的签约经理。你今晚的表现很有潜力。我们愿意提供签约合作：保底月薪2万，公司提供流量扶持、选题策划、设备场地。」

两万块……那能还好几个月的债……

景别：中景 / 出租屋 / 红色全息警告

"流量"投射出合同条款——

⚠️ 警告：陷阱合同
• 收入分成：70%归MCN
• 独家绑定：3年
• 违约金：50万
• 你 = 给别人打工的工具人

签了你就是给别人打工的工具人。拒绝他。

可是两万块钱……

你现在欠12万。2万能还几个月？但如果你自己做到十万粉，你值200万。

景别：特写 / 流量 / 罕见严肃

"流量"第一次没有阴阳怪气。小三角的光变得沉稳而坚定。

我说认真的。签约是最安全的路，但安全的路不会让你到达你想去的地方。

景别：特写 / 晨光 / 转折

陈小北想了一整晚。窗外天亮了。

清晨的光照在他脸上，那件灰卫衣在这一刻看起来像是战甲。

景别：特写 / 手指打字 / 晨光

他打了两个字，发送——

不好意思，我自己来。

景别：中景 / MCN办公室 / 冷光

MCN星探看到回复，冷笑一声。

你会后悔的。这个行业，没有公司扶持的素人，平均寿命不到3个月。

陈小北的回复很快——

那我就做不平均的那一个。

景别：分屏 / 倒计时+紧急 / 红色警告

倒计时最后一小时。粉丝卡在——

97

系统倒计时在眼角闪烁红光。陈小北手忙脚乱地架起手机，紧急开播。

景别：近景 / 情感特写 / 真实

这一次他没有吐槽，没有段子。

今天有个MCN公司找我签约，保底月薪2万。我拒绝了。

你们知道为什么吗？

因为12万的债不是2万能还的。但我的命，不值70%的分成。

直播间安静了三秒。然后弹幕爆了——

景别：极端特写 / 数字 / 高潮

97 → 98 → 99 → 100!

「牛逼！」「拒绝MCN的男人」「关注！关注！」「这种人不火天理难容」

景别：全景 / 出租屋 / 金色粒子 / 高潮
🎊 任务完成！
等级提升：素人 → 小透明
解锁技能：口才 Lv.1
获得：500 流量点
当前粉丝：137

金色的粒子在出租屋里炸开。虽然只是全息投影，但在这间月租600的房间里，它比任何烟花都好看。

景别：全身 / 升级动画 / 史诗感

陈小北站在出租屋正中间，被金色光芒包裹。

137个人。有137个陌生人，愿意在这个深夜里，记住我的名字。

景别：特写 / 流量 / 金色暖光

"流量"飘过来，一反常态地发出温暖的金色光芒。

不错。你用了23小时47分。还算……没丢人。

它的语气还是那么欠揍，但这一次，陈小北听出了别的东西。

景别：中景 / 出租屋 / 暖光 / 平静

关播以后。出租屋恢复了安静。

陈小北对着手机上"粉丝：137"的数字，傻笑了整整五分钟。

· · ·
景别：特写 / 新任务界面 / 科幻

手机震动。系统新任务——

🎯 进阶任务
• 7天内达到 1000 粉丝

⏰ 倒计时：7天

直播带货？我连卖什么都不知道……

场景：MCN星探的豪车 / 夜景 / 城市霓虹

同一时间，那个MCN星探在豪车里发了一条朋友圈——

「有些人不知道天高地厚。市场会教他做人。@全体达人」

陈小北看着这条朋友圈。

嘴角慢慢上扬。不是苦笑，是那种"你等着看"的笑。

景别：过肩 / 桌面 / 暖+冷光

"流量"飘过来——

怎么，怕了？

怕个屁。开始研究怎么带货吧。

行。先说好——你那个灰卫衣别穿了，影响转化率。

就这一件干净的。

……我是不是分配到了一个丐帮用户？

景别：全景 / 窗前 / 城市夜景 / 终章

出租屋的窗户很小，但城市的灯火很亮。

陈小北站在窗前，"流量"浮在他身侧。灰色卫衣的轮廓映在玻璃上，背后是万家灯火。

137个粉丝。12万的债。一个毒舌的三角形。

够了。够开始了。
