第一章 · 我不是来玩游戏的
"我不是来玩游戏的，我是来赢的。"
↓ 向下滑动开始阅读 ↓
— 第一幕 · 散场 —
【远景·仰拍 / 写字楼·黄昏】

夕阳把整栋大楼的玻璃幕墙染成了橘红色。我抱着纸箱走出旋转门，感觉这光照在脸上有点刺眼。

三年了。AI做了三年，最后给别人做了嫁衣。
【特写 / 纸箱内部】

箱子里装着全部家当——团队合照、仙人掌、陪我熬过无数通宵的笔记本电脑。

说不难过是假的。但难过有什么用？
【中景·背影 / 街道·暮色】

西装皱巴巴的，领带松着，影子被夕阳拉得老长。这条路走了三年，今天是最后一次。

【分镜 / 左现在·右闪回】
签字那天，陈总笑得跟弥勒佛似的。"小朱啊，你技术不错，可惜不懂资本。"

我咬了咬牙。不懂资本？行，记住了。

【鸟瞰 / 夜��闹市】

不知道走了多久，天黑了。霓虹灯花花绿绿，我在人群里像个幽灵。

突然——街角网吧的蓝光吸引了我。里面传出一阵吵闹声。

— 第二幕 · 偶遇 —
【广角 / 网吧·蓝光】

网吧里乱成一锅粥。四个年轻人围着显示器吵得面红耳赤。桌上全是能量饮料和薯片袋子。

【特写 / 小鱼·蓝光映照】
小鱼

"这破战队不打了！每次都是这样，根本赢不了！"

金色刺猬头，眼神凶得像要吃人。键盘被他一巴掌拍飞。

【中景 / 网吧门口·逆光】

我不知道为什么停下了脚步。也许是少年摔键盘的样子让我想起了三��前的自己。

我把纸箱放在脚边，走了进去。

【中景·侧面 / 角落】

角落找了个位子坐下，假装随便看看。但眼睛一直盯着他们的屏幕。

创业者的职业病——看到任何团队运作，都忍不住分析。
【过肩 / 游戏屏幕】

配合一塌糊涂。走位重叠、技能浪费、团战没优先级……核心技术不错，但运营全是零。

可那个金毛小子的操作……手速快得离谱。
【极特写 / 眼部·蓝光】

我看到了什么？一支被严重低估的"股票"。

这不就是——天使轮的最佳标的吗？
【分镜 / 屏幕+餐巾纸】

我随手抓了张餐巾纸画箭头。上面是他们混乱的站位，下面是我重新规划的阵型。

如果把辅助位拉到这里，C位进场角度改成……嗯，有意思。
— 第三幕 · 交锋 —
⚡ 决策点 1

一支有潜力的队伍正在崩溃。要不要管？

A. 管闲事帮一把
B. 转头离开
→ 我选了A。看到有潜力的人和事，我没法袖手旁观。这就是创业者的毛病。
【中景 / 起身走向团队】

我站起来，纸箱丢在身后，大步走向他们。

【中景 / 朱江指着屏幕·团队惊讶】

我指着小鱼的屏幕："你们刚才团战，辅助位站错了。"

四个人齐刷刷扭头看我。小鱼的眼神像刀子一样。

【中景 / 对峙·仰拍】
小鱼

"你谁啊？大叔你会打游戏吗？"

他比我高半头，指着我鼻子，一脸不屑。旁边胖虎紧张地缩了缩脖子。

【特写 / 朱江微笑】
我

"我不会打游戏。但我会赢。"

【中景 / 展示手机数据】

我掏出手机，打开刚做的即兴分析——他们对手最近十场的弱点热力图。

小鱼的表情从不屑变成了好奇。胖虎把耳机摘了下来凑过来看。

⚡ 决策点 2

小鱼不服气，要跟我打一局证明自己。我操作稀烂被暴打——

A. 认输服软
B. "我说了我不会打游戏，但我能让你们赢"
→ 我选了B。不靠蛮力，靠脑子赢。这是创业者的自信。
【仰拍 / 小鱼递鼠标】
小鱼

"行啊大叔，你行你上啊！"

他把鼠标往我手里一塞。眼神写满了挑衅。

【广角 / 朱江坐姿·搞笑】

我坐到电脑前——姿势全错。坐得太直，离屏幕太远，鼠标握得像拿筷子。

胖虎在后面憋笑憋得脸都红了。
【特写 / 游戏画面·阵亡】

进游戏三秒，我的角色被连招秒杀。击杀提示刷了满屏。

我可能创造了"史上最快阵亡"的记录。
【中景 / 全队爆笑】

小鱼笑得弯了腰。胖虎拍着大腿。眼镜推了推眼镜偷偷笑。

我坐在那，嘴角微微上扬。

让他们笑吧。我需要的不是他们的敬畏，是他们的信任。
【特写 / 推开键盘·掏手机】

笑声还没停，我把键盘一推，掏出手机。脸上的表情从随意切换到认真模式。

笑声慢慢安静了。

【广角 / 投屏战术分析】

我把手机投到网吧大屏上——战术分析报告、热力图、对手弱点、最优打法路径。

专业级的分析。沉默了三秒。

胖虎

"卧槽……这比我们教练做得都专业……"

【特写 / 小鱼表情变化】

小鱼的笑容僵住了。他看着屏幕上的数据，眼里第一次出现了认真的光。

我看到了他眼里那道裂缝——傲慢的铠甲，第一次出现了裂痕。
— 第四幕 · 散伙危机 —
【广角 / 打烊后·灰暗】

网吧打烊了。四个人围坐在一起，谁也不说话。空气里弥漫着散伙的味道。

【特写 / 门上的催租通知】

门上贴着房东的催租通知，红色印章刺眼。玻璃上映出几个人沉默的影子。

【特写 / 胖虎·忍泪】

胖虎一直是队里的开心果。但现在他在偷偷刷招聘软件，耳机挂在脖子上，眼角泛红。

他不想走。但他得吃饭。
【中景·侧光 / 门框外·暗影】

我站在门外，听到了一切。手指死死攥着门框。

又要做一个疯狂的决定了。
⚡ 决策点 3

战队要散了。房租交不起，赞助商跑了。

A. 掏钱投资这支战队
B. 只给建议不投钱
→ 我选了A。创业者看到好产品就想All-in。被收购赔的钱——砸进去。"当创业做。"
【中景·逆光 / 朱江大步走入】

我推开门，手机亮着转账页面，大步走了进去。背后的灯光把我的影子拉到他们脚下。

我

"散什么伙？你们缺的不是实力，是管理。这事我懂。"

【特写 / 手机转账确认】

拇指悬在"确认"按钮上方。手机屏幕上映着我的脸——在笑。

疯了吗？也许吧。但不疯不活。

按下去了。

【中景 / 全员震惊】

小鱼嘴巴张成了O型。胖虎手机掉在地上，招聘页面还亮着。眼镜的眼镜滑到鼻尖，来不及推。

空气安静了整整五秒。然后胖虎冒出一句："大叔……你不是骗子吧？"
— 第五幕 · 上任 —
【广角 / 训练室·破败】

第二天。我穿着polo衫站在所谓的"训练室"里——空调漏水、电线乱挂、椅子破得像从垃圾堆里捡的。

……我投了个什么？
【中景 / 小鱼指空调·搞笑】
小鱼

"朱总，空调坏了，麻烦您修一下？"

他笑嘻嘻的。胖虎在旁边吃薯片看热闹。

这小子……在试探我。
【中景·仰拍 / 梯子上修空调】

我踩在一把摇摇晃晃的梯子上，手里拿着扳手，名表在脏兮兮的空调旁闪闪发光。

从AI创业CEO，到网吧维修工。我的职业生涯真是越来越精彩了。
【蒙太奇 / 杂活集锦】

拖地、修椅子、理线缆、搬水……一整天我干了比三年创业还多的体力活。

从他们的游戏椅缝隙里，我偶尔能看到几双偷偷打量我的眼睛。

嘲笑在减少。好奇在增加。
【中景 / 沙发·傍晚】

傍晚，他们都走了。我瘫在破沙发上，浑身酸痛，手里攥着功能饮料。

训练室稍微干净了点。白板上写着我拟的第一版训练计划。

今天是第一天。一切刚刚开始。
— 第六幕 · 发现 —
【中景 / 深夜·笔记本光】

深夜。训练室只剩我和笔记本的光。桌上摞着三个咖啡杯。窗外月光洒进来。

我在分析今天录下来的每个人的操作数据。

【极特写 / 屏幕数据】

反应速度图表上，有一个数据点高得离谱——远远超过其他所有人，甚至越过了"全球前0.1%"的阈值线。

标签写着：林小鱼。

【特写 / 朱江震惊·笔记本光】

我瞪大了眼睛。嘴角不由自主地咧开——这是今天第一个真心的笑容。

我（轻声）

"这小子……是个怪物。"

⚡ 决策点 4

我发现小鱼的天赋惊人——反应速度全球前0.1%。要告诉他吗？

A. 告诉小鱼让他自信
B. 先不说，暗中观察培养
→ 我选了B。信息是武器，不到时候不亮底牌。先让他按我的计划练。
【广角 / 仰头·黑暗中】

我靠在椅背上，看着天花板。数据图在屏幕上发着微光。

手上有一张王牌。现在要做的，是帮他打好基础，让他在最关键的时刻……爆发。

这支队伍，不止能赢。

能拿冠军。

— 与此同时 —
【广角 / 豪华办公室·夜景】

城市另一端。顶楼办公室，落地窗外万家灯火。

一个秃顶大肚的男人坐在真皮座椅里，翻着平板电脑上的一份资料。

【特写 / 陈总·阴影半脸】

平板的光映在他下巴上。那个冷笑，我太熟悉了。

陈总

"朱江……又冒出来了？有意思。"

他放下平板，拿起桌上的威士忌晃了晃。

陈总

"电竞？他以为换个赛道我就追不上他？"

他笑了。笑声在空荡的办公室里回荡。

第一章 · 完

战队重建刚刚开始。
但猎人的目光，已经锁定了猎物。
