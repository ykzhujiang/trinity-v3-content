ACT 1

崩溃边缘
第47次融资路演，第47次失败。"脉冲科技"的银行账户还剩11万3千块。够发一个月工资。
我无意识地敲了一下回车键，屏幕弹出编译错误。跟我的人生一样——语法没问题，就是跑不通。
老马
「江哥，咖啡。我刚把情感识别模块的准确率从78%推到了83%。」
老马从不问"公司还行吗"。他只汇报进展。这是他的忠诚方式——假装一切正常，然后默默把活干到最好。
我接过咖啡，注意到他的格子衫扣子扣错了一颗。这个人啊。
第三天没怎么睡了。我站起来想去洗把脸——然后世界翻了个个儿。
老马（声音变形）
「江哥？！江哥你怎么了——」
最后一个清晰画面，是咖啡杯翻倒，棕色液体在白色键盘上蔓延。
在黑暗里，我听到了一个声音。不是老马的。更像是……代码编译完成的提示音。
[叮——] 情感计算核心加载完成
宿主生物信号接入中……接入成功
心跳系统 v0.1 启动
我睁开眼，看到了不该看到的东西。
目标：马志远
情绪：担忧(87%)
诚意指数：96
好感度：91
隐藏意图：🔒(需升级)
……什么鬼？

[ 决策点 1 ] 第一反应

A) 以为自己疯了，去医院检查 → 理性选择
B) 立刻测试系统功能，当成新工具 → 黑客精神
C) 吓得大叫把老马吵醒 → 搞笑选择
→ 选B。遇到新系统第一反应是拆开看结构——这是黑客的本能。
黑客的本能——遇到新系统，先看自己的数据。
目标：朱江（宿主）
情绪：震惊(42%) + 好奇(38%) + 兴奋(20%)
诚意指数：对自己不适用
好感度：自恋指数72
隐藏意图：想知道这玩意儿怎么卸载
……自恋指数72？隐藏意图"想卸载"？这系统是不是有点太诚实了。
老马
「江哥你醒了？你昨晚直接倒下去了，吓死我了。我叫了120但你心跳血压都正常，就没送你去——」
我看着老马头顶浮动的面板。诚意指数96。这个人，是真的担心我。
好感度91。我欠这个格子衫男人太多了。
[短信] 朱总，新世纪创投刘总愿意见您最后一次。今天下午2点，外滩18号三楼。另有两位投资人同场。——秘书小周
最后一次机会。11万3千块的命。
但这一次，我有了一点不一样的东西。
检测到宿主肾上腺素上升。建议：深呼吸。或者直接去赢。

ACT 2

融资会议 · 用系统看穿谎言
外滩18号。上海最贵的写字楼之一。我上次来这里，是三年前脉冲科技A轮的时候。那时候意气风发。
现在我兜里的公司账户只有11万。西装是三年前那套，还合身——因为创业以来一直没时间吃饭。好吧，也可能是越来越胖了，只是西装质量好。
宿主外表评分：7.2/10
建议：把那缕翘起来的头发按下去。
……这系统真的很多嘴。
刘总
「朱总请坐！好久不见。气色不错嘛！」
刘建国 / 情绪：无聊(65%) + 敷衍(30%)
诚意指数：23
好感度：35
隐藏意图：🔒
诚意指数23。他说"气色不错"的时候，真实想法大概是"这人看着快撑不下去了"。
刘建国 / 诚意指数：23 /「这项目有意思」
陈志平 / 诚意指数：11 /「我们基金很看好情感计算」
王美琳 / 诚意指数：37 /「市场空间确实很大」
三个人里最诚实的那个，诚意也只有37。我过去47次融资失败，大概每一次都是在跟这样的诚意指数交谈。
区别是——过去我不知道。

[ 决策点 2 ] 面对谎言

A) 当面揭穿他们的敷衍 → 霹雳手段
B) 顺着他们演下去，寻找突破口 → 战术选择
C) 心灰意冷，准备放弃 → 投降选择
→ 选B（表面）+ A（内心）。菩萨心肠但有策略。
我
「三位，我今天不讲PPT了。」
三人微微吃惊。
我
「我讲一个真实的事情。上个月，我们的情感AI在一次盲测中，准确率达到了83%——读人的情绪，比大多数心理咨询师都准。但这不是重点。」
我盯着刘总的面板。诚意指数从23……慢慢升到了29。好，有反应。
我
「重点是，我发现了一件事——人在说谎的时候，面部微表情的组合模式，和说真话时的差异率是94.7%。」
刘总的诚意指数掉回了18。他紧张了。
有意思。当我说出"94.7%"这个数字的时候——
刘建国 / 情绪：紧张(71%) / 诚意指数：18→41 / 目标开始认真评估威胁
陈志平 / 情绪：警觉(82%) / 诚意指数：11→35
王美琳 / 情绪：兴趣(66%) / 诚意指数：37→52
人在感到威胁的时候，反而会变得诚实。因为他们需要认真对待你了。
陈总
「朱总，你这个准确率……在什么数据集上测的？样本量多少？」
陈总的诚意指数到了35。从"敷衍来坐坐"变成了"让我认真看看"。但35离投资还差得远。
我
「3万样本，跨文化验证，中英日三语。论文在投AAAI。」
检测到宿主说谎倾向。论文实际还在写。
……好吧，论文确实还没写完。但数据是真的。系统你闭嘴。
秘书
「刘总，深渊资本的苏总到了。」
刘总
「哦！苏总，快请。」
一个女人走进来。168cm，齐耳短发，纯黑极简西装加白衬衫，眼神锐利。全场微愣——没人预期第四个人。
我下意识看向她头顶——
目标：苏晚
情绪：？？？
诚意指数：？？？
好感度：？？？
隐藏意图：？？？
⚠️ 警告：数据读取失败。原因未知。
……什么？
从今天早上到现在，我看了老马、保安、外卖小哥、地铁上的陌生人、三个投资人——每个人都有数据。
但她——全部是问号。
我的系统第一次失灵了。偏偏是在一个我最需要读懂的人面前。
苏晚
「朱总，我看过你们的技术文档。83%的情绪识别准确率，在行业里是天花板了。」
苏晚
「但我想问一个你可能没想过的问题——你的AI能识别情绪，但它能识别"不想被识别"的情绪吗？」
我愣了三秒。不是因为问题难，而是因为——她这个问题，精确地击中了我心跳系统的bug。
她怎么知道的？
⚠️ 目标持续无法读取。建议：保持警惕。或者……保持好奇。
刘总
「朱总，我们回去研究研究，保持联系！」
刘建国 / 诚意指数：12 /「保持联系」= 再也不见
我已经不在意他了。因为我现在全部注意力都在那个读不出数据的女人身上。
苏晚（没起身）
「朱总，你有时间吗？我想单独聊聊。」
她的手指轻轻敲桌面——一下、两下、三下，节奏精确。
苏晚
「深渊资本对情感计算赛道有战略布局。我们不做财务投资。」
我
「那你们做什么？」
苏晚
「我们找……特殊的人。你的技术很好，但让我更感兴趣的，不是你的AI。」
我
「那是什么？」
苏晚（停顿两秒）
「是你这个人。」
⚠️ 读取失败 ×47次
建议放弃自动分析，改用传统方式——直觉。
传统方式？就是说，像一个普通人一样，猜？
我已经很久没用过直觉了。

[ 决策点 3 ] 面对苏晚的提议

A) 直接问她"深渊资本"的真实背景 → 直球
B) 先假装不感兴趣，试探她的底线 → 商业博弈
C) 跟着直觉走，答应进一步接触 → 冒险
→ 选C。菩萨心肠加黑客好奇心——我无法抗拒"无法解读"的谜题。

ACT 3

悬念 · 读不懂的人
苏晚
「这是我们的初步意向书。不需要你现在签。看完后，三天内给我答复。」
苏晚
「条件很简单——我们投2000万，占15%。但有一个附加条款。」
我
「什么条款？」
苏晚
「在投资期内，我需要深度参与你们的核心研发。不是监督——是参与。」
投资人要参与核心研发？这不正常。任何一个创业者都会警觉。
但我的系统读不出她的意图。我只能靠一样东西——她眼睛里的光。那种光，我在自己创业第一天的眼睛里见过。
走出外滩18号的时候，上海的夜风很凉。
我用心跳系统扫了路上的每个人——跑步的大爷（情绪：愉悦85%），遛狗的情侣（好感度：双向78），卖烤红薯的大叔（隐藏意图：想早点收摊）。
每个人都是打开的书。唯独她，苏晚，是一扇上了锁的门。
我讨厌上锁的门。但我更讨厌自己想去开锁的冲动。
老马（电话里）
「江哥！情感模块出了个奇怪的bug——今天下午突然有一段异常数据涌入我们的服务器。来源不明。像是……有人在逆向工程我们的算法。」
⚠️ 检测到外部访问。核心模块被扫描。
来源IP……已被深度伪装，无法追踪。
有人在扫描我们的技术。在苏晚出现的同一天。
巧合？
宿主心跳加速至92bpm。建议：这不是巧合。
这一次，我同意系统的建议。
老马
「你看这个——有人用极其精细的方法在模拟我们的情感识别算法。不是抄，是在……测试边界。像在找弱点。」
我盯着屏幕上的数据流。然后我想起了苏晚的问题——
"你的AI能识别不想被识别的情绪吗？"
她不是在问一个学术问题。她是在告诉我——她知道我们的弱点。
检测到宿主肾上腺素+多巴胺同时飙升
情绪模式：恐惧(30%) + 兴奋(40%) + 好奇(30%)
这是一个危险的组合，但宿主历史记录显示——你最喜欢这种感觉。
系统说得对。我是一个被上锁的门吸引的人。而现在，锁里面可能藏着一只老虎。
我更想开锁了。
