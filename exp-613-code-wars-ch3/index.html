第三章

预测之眼

代码暗战 · V5原创长篇
第一幕 逃离猎场

面部识别已锁定。走廊监控的红灯疯狂闪烁，我大概还有90秒。

小鱼："老板，酒店安防系统我已经摸清了，消防通道在你左手边18米。但——你的面部数据已经被上传到天网本地服务器了。"

苏小棠突然从旁边拉住我的袖子："跟我走，我知道这栋楼的后厨通道，以前天网团建来过这个酒店。"

我们穿过后厨，经过一群正在切三文鱼的厨师。

小鱼："老板，你现在的逃跑路线和你上次从投资人办公室出来一样曲折，区别是上次是比喻意义上的。"

从地下车库出去时，苏小棠的手在发抖。我递给她一瓶水。

我："第一次被追？"

她摇头："第三次。前两次我是一个人。"

小鱼："面部投毒方案已规划。我准备生成10万张和你长得差不多的AI人脸。放心，都比你帅一点，不会引起怀疑。"

决策点 D-7

天网已有我的面部数据。48小时内就能确认"幽灵"=朱江。

A：先下手为强——删除面部数据
B：投毒策略——注入10万张噪音人脸
C：赌时间差——48小时内拿到证据

最优雅的防御不是删除痕迹，而是让痕迹变成噪音。

深圳的霓虹灯在车窗外流淌。我靠在后座闭上眼睛。今晚的酒店不能回了。

第二幕 U盘的秘密

苏小棠的安全屋——城中村的一间小公寓。满墙二次元海报和打印的网络安全报告，桌上三台笔记本同时亮着。

这是我见过最赛博朋克的房间——不是因为科技感，是因为混乱程度。

开始破解U盘。三层加密：高级加密标准、自定义混淆、硬件绑定密钥。我和苏小棠并排坐下，四只手在两台键盘上翻飞。

苏小棠的程序员习惯：一边逆向工程一边无意识地嗑瓜子。桌上的瓜子壳堆得比键盘还高。

四个小时过去了，瓜子壳又高了一层。我忍不住侧头看了一眼——她完全没注意到。

小鱼："这个加密方案的作者有洁癖——命名规范完美、注释详尽、还用了代码美化工具。我猜是个处女座。"

苏小棠："……是我前同事赵凯，确实是处女座。"

前两层破了。第三层——硬件绑定，需要赵凯的原始工作电脑。死路。

但已解密的部分，已经够震撼了。

天网数据交易日志。规模比我想象的大得多——不是简单卖用户数据。

天网在做的事是：训练一个"预测控制AI"。用3亿用户的行为数据，预测用户下一步会做什么——然后引导他们的行为。

一个叫天眼的模块。预测准确率：87.3%。每个月提升0.5%。

18个月后，它能预测每个用户90%以上的行为。

小鱼："老板……这不是数据贩卖。这是行为控制。他们在训练的东西，用通俗的话说——读心术。"

小鱼："老板，我不是卡了，我是在消化。这个模型的参数量比我大一万倍。我终于理解了什么叫学历碾压。"

苏小棠的声音在发抖，但不是因为恐惧。

"我当初发现这个的时候，以为是产品优化。后来我看到了控制模块——它不只是预测，它会主动推送内容来改变用户原本会做的决定。"

第三幕 暗网拍卖

决策点 D-8

苏小棠的前导师王教授拿了天网的研究经费——他知道天眼的存在。

A：联系王教授，说服他公开站出来
B：不信任——拿了钱就是利益相关方
C：先调查王教授到底知道多少

黑客的第一课是信息不足时不做决定。

小鱼："这句话如果用在你之前的融资决策上……算了我不说了。"

小鱼监控暗网时发现异常——一个叫天眼碎片的拍卖。有人在暗网出售预测控制AI的部分训练数据和模型权重。

起拍价500万泰达币。已有12个买家出价。

我决定潜入暗网拍卖会——不是买东西，而是追踪卖家身份。

小鱼："你现在是'数据经纪人幽灵经纪人888'。我给你编了一份暗网履历——27次成功交易、零差评。"

我："你是不是把我的创业经历改了改就用了？"

小鱼："主要是把'融资'改成了'洗钱'，核心竞争力差不多。"

虚拟专网套三层、加密通信、IP跳转7个国家。潜入暗网拍卖会。

拍卖过程中，小鱼分析出买家通讯模式——其中一个买家的加密签名和陈天明手机上的APP完全一致。

陈天明自己在暗网买回自己公司泄露的数据。

陈天明自己买回自己公司泄露的数据？为什么？

顺着卖家的数字指纹追踪——追到了天网深圳研发中心的一个内网IP。

内鬼。天网内部有人在偷数据出来卖。

天网的内鬼可能是我的潜在盟友，也可能是更危险的敌人。

决策点 D-9

天网内鬼在暗网卖公司核心数据。此人是盟友还是更大的威胁？

A：接触内鬼，试图策反
B：匿名举报给陈天明，趁乱渔利
C：继续监控，等待时机

你不一定要成为棋手，有时候看清整盘棋比下一步棋更重要。

小鱼："终于选了一次低风险选项！我要截屏保存，作为证据证明你偶尔也会理性。"

第四幕 王教授的真相

苏小棠在大学附近的咖啡馆约见王教授。我通过耳机远程监听。

王教授："小棠，你不该来找我的。你辞职后天网就在监控和你有联系的人。"

王教授压低声音。

"天眼不是陈天明的发明。核心算法来自5年前一篇被撤稿的论文——作者是一个叫Sigma的匿名研究者。陈天明花了三年才重建了70%的模型。"

"而Sigma……三个月前开始在暗网活动。天网的数据泄露——是Sigma在取回自己的东西。"

小鱼："老板，追踪幽灵的那个天网黑客的代码风格……和Sigma论文中的代码风格——

匹配度89%。

猎杀我的人，不是天网的员工。"

猎杀我的人，不是天网的员工——是Sigma本人。

棋盘上不是两个人了。是三个：我、陈天明、和一个叫Sigma的幽灵之上的幽灵。

终幕 三方博弈

我站在安全屋的窗边，看着深圳的夜景。远处的高楼像一块块发光的棋盘。

陈天明想控制3亿用户的行为。Sigma想取回自己的技术。而我——只是想阻止这一切。

三方博弈。每一方都有自己的目的，每一方都可能成为另外两方的敌人。

小鱼："苏小棠发来截图——她前同事赵凯，就是那个处女座加密专家——今天没去上班。社交媒体全部删除。最后一条朋友圈就两个字：'对不起'。"

我猛地站起来。赵凯可能就是Sigma在天网内部的合作者。他跑了，说明事态在加速。

手机屏幕亮了。一条加密消息。发送者：Sigma。

"幽灵，我们该谈谈了。"
