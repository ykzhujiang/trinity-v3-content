循 环
01
07:00
场景：卧室 / 中景 / 平视
闹钟准时在七点响起。今天是决定公司命运的日子——和赵鹏的融资谈判。
我伸了个懒腰，满血复活的感觉。三个月的准备，今天就是见分晓的时候。
场景：浴室 / 中景 / 通过镜面反射
镜子里的我，看起来还不错。三十出头，正是能拼能打的时候。
我理了理头发，对着镜子里的自己点了点头。今天这场仗，必须赢。
场景：轿车后座 / 侧面特写 / 车窗倒影
车窗外是熟悉的CBD天际线，玻璃幕墙在阳光下闪着光。我的公司就在其中一栋里——虽然只占了半层。
但很快就不一样了。拿到这笔融资，一切都会不一样。
场景：高层会议室 / 广角全景 / 平视
会议室在38层，整面玻璃幕墙，能看到半个城市。赵鹏已经坐在长桌另一端，两个助理像门神一样分列左右。
这排场……是想给我一个下马威？
"赵总，久仰。"我微笑着伸出手。
场景：会议桌面 / 特写 / 低角度浅景深
寒暄不到三分钟，赵鹏就开门见山了。一个牛皮纸文件夹沿着会议桌滑过来。
"朱总，先看看这个。"赵鹏的声音不带任何感情。
他食指上的金戒指在灯光下晃了一下。我打开文件夹——
心跳骤然加速。
这是我们的核心算法审计报告。而且是内部版本——这东西怎么会在他手上？
场景：会议室门口 / 中景 / 从室内向外拍
"基于这些问题，我们给出的估值是……你们报价的十分之一。"
十分之一？！这不是谈判，这是抢劫！
"赵总，这个价格，我们没什么好谈的了。"
我站起来，椅子发出刺耳的摩擦声。推开玻璃门的时候，我余光瞥到赵鹏嘴角微微上扬。
那个笑容……像是一切尽在掌握。
场景：街道斑马线 / 低角度 / 动态模糊
满脑子都是赵鹏那个笑容，过马路的时候完全没注意——
刺眼的白光。
刹车声，喇叭声，骨头碎裂的声音，全部混在一起。
疼。
然后……什么都没有了。

07:00
场景：卧室 / 中景 / 平视
我猛地坐起来，浑身是汗。手本能地摸向胸口——
完好的。没有伤口。
手机屏幕亮着：7:00 AM。
做梦？……那也太真实了吧。
场景：办公室大堂 / 过肩镜头
到了公司，小陈拿着平板迎上来：
"老板，赵鹏那边确认了，下午两点——"
等等。这句话……我昨天听过。一模一样。
我停下脚步，盯着小陈。他被我看得有点发毛。
如果不是梦呢？
场景：会议室 / 中景 / 平视
这次我有备而来。提前准备了算法审计的回应材料，当赵鹏把文件推过来的时候——
"赵总，关于算法审计的问题，我这边也有份材料。"
赵鹏眉头挑了一下，显然没预料到我会有准备。但那只是一瞬间。
"朱总准备得不错。不过——"他从公文包里又抽出一份文件。"看看这个？"
场景：会议室 / 特写反应镜头 / 单顶光
那是一份协议。签名栏上赫然写着——林薇。
林薇？！我的CTO？我的联合创始人？
协议内容是关于核心AI算法的技术转让。日期就在三个月前。
这不可能……我们一起创业四年了……
脑子里像有什么东西碎了。
◆ 决策点 D-1
发现林薇的秘密协议——我该怎么做？
A. 当面质问林薇 B. 暗中调查，不打草惊蛇 C. 装作不知道，继续谈判
我的直觉告诉我：先搞清楚真相，再做决定。黑客的第一课——信息不完整时，永远不要暴露自己。
场景：会议室 / 俯瞰 / 抽象时空扭曲
但这一次的打击太大了。我机械地走出会议室，脑子里全是那份协议——
林薇为什么要这么做……
眼前一黑。又是那种被抽离现实的感觉。
不是梦。
是循环。
循 环
03
07:00
场景：卧室 / 中景 / 侧低角度
第三次醒来，我没有慌。坐在床边，双肘撑膝，盯着自己的手掌。
好。我接受这个设定。时间循环，记忆保留，身体重置。
那就用这个Bug，把所有真相查个底朝天。
床头的笔记本上，我写下了第一行字：「第三次。今天不去谈判。跟踪林薇。」
场景：地下停车场 / 远景 / 低角度 / 黑色电影光影
换了身连帽卫衣和牛仔裤，帽子压低。上午十一点，林薇没来公司，直接开车去了CBD对面的商务楼。
我躲在柱子后面，看着她走进一辆银色轿车。
跟了二十分钟，她在金融街一家私密会所停下。
场景：咖啡馆窗边 / 中景 / 玻璃反射
我在对面咖啡馆找了个靠窗位置。假装看手机，余光锁定——
林薇对面坐的那个人……是赵鹏的助理。
他们压低声音在说什么，表情都很紧张。林薇一直在摇头，但那个助理似乎在施压。
这不像是在做交易。更像是……在威胁。
场景：走廊墙边 / 极端特写 / 斜切阴影
我跟到了会所楼上的私人房间外。贴着墙壁，屏住呼吸——
「……你不配合，你知道你妈在哪家医院。」
！！！
林薇的母亲住院的事，我知道。但我不知道那家医院是……
赵鹏控制的。内部有卧底。林薇不是背叛我，她是被胁迫的。
◆ 决策点 D-2
偷听被发现——门突然打开——
A. 正面对峙 B. 假装路过 C. 跑！（但下次循环，正面对峙）
身体比脑子快——先跑了再说。但信息已经到手，下一次循环不会再怂。
场景：旋转楼梯 / 俯瞰动态 / 运动模糊
转身就跑。身后脚步声追了上来——
楼梯！靠，踩空了——
整个人向后翻倒，手抓向栏杆但只摸到了空气。旋转楼梯变成了一个巨大的漩涡——
又来了。至少这次摔死比被车撞舒服一点……才怪。

07:00
场景：客厅 / 广角 / 暖灯+暗室
客厅的白墙变成了情报板。便利贴、红线、时间轴、人物关系图。
我把它当成了一场大型存档读档游戏。每次循环就是一条命——而我有无限条命。
这次不急。系统性地收集情报。
场景：多重分镜 / 风格化分屏
每次循环走不同路线。
第一条线：去谈判，但故意输掉，观察赵鹏团队的反应模式。
第二条线：跟踪林薇，这次带了录音设备。
第三条线：黑进公司服务器，查代码访问日志。
第四条线：直接去医院摸底。
存档。读档。再来。
场景：机房 / 低角度 / 绿光LED
凌晨三点潜入自己公司的机房——说起来很讽刺，CEO要偷偷查自己公司的服务器。
日志不会骗人。三个月前，核心算法文件被复制过。外发IP……
解析出来的地址指向一个匿名中转节点。但数据包大小和时间戳和林薇那份协议完全吻合。
不是林薇主动泄露的。代码是被他们用林薇的权限偷走的。
场景：医院外 / 远景 / 冷暖对比
透过医院窗户，林薇正坐在病床边，握着她母亲的手。
她看起来很憔悴。比公司里任何时候都脆弱。
这家医院叫"盛安"。查了一下——大股东是赵鹏背后那个科技集团的关联公司。
她母亲在他们手里。林薇根本没有选择。
◆ 决策点 D-3
得知林薇是被胁迫的——怎么做？
A. 告诉林薇"我知道了" B. 默默帮她，不让她知道 C. 把这个信息做筹码
她够苦了。不需要知道有人在暗中保护她——做就行了。
场景：办公室 / 中景 / 明亮喜感
到了第五次循环，有些事情变得好笑起来。
小陈走过来刚张嘴，我接上：
"赵鹏那边确认了，下午两点，38层会议室，对吧？"
小陈嘴巴半张着，眼珠子差点掉出来。
场景：办公室 / 双人特写 / 喜剧
"你……你下一句要说'老板别紧张'。"
小陈把平板护在胸前，后退两步，看我的眼神像看鬼：
"老板你……怎么知道？？？"
忍住。不能笑。保持CEO的威严。
没忍住。笑出了声。
场景：多场景蒙太奇 / 动态拼接
两次循环，系统性情报收集——
① 备份了所有服务器日志和入侵痕迹。
② 拿到了赵鹏三家关联公司的工商信息。
③ 录下了赵鹏助理威胁林薇的对话。
④ 找到了另一个被赵鹏吞并的创业公司创始人——他愿意作证。
拼图快完成了。
场景：书房电脑前 / 中景 / 暖光喜感
对了，我试过用"前世记忆"炒股。
然后发现循环只有一天。
收盘价我倒是知道了，问题是——明天的数据没用，因为永远到不了明天。
看着K线图，苦笑。
命运给了我一个外挂，但附带了一条讽刺性的使用条款。

07:00
场景：会议室入口 / 低角度英雄镜头 / 逆光
第六次循环。这次不是去挨打——是去还手。
我带着五次循环积累的全部情报走进了那间会议室。
赵鹏照例坐在对面，准备了他的那套表演。
可惜，你不知道我已经看了五遍了。
场景：会议桌 / 中景 / 权力翻转
赵鹏照例推出那份文件。我接过来，看都没看：
"赵总，这份文件我已经看过了。"
在他还没反应过来的时候，我从自己的包里一张一张抽出照片放在桌上。
"倒是这些，你可能没看过——盛安医院的实控链、你助理威胁我合伙人的录音文字稿、还有……赵鹏关联公司的资金流水。"
场景：赵鹏 / 特写 / 阴冷光线
赵鹏脸色变了，但只是一瞬间。随即恢复了那副老狐狸的镇定。
"朱总啊朱总……你查了不少东西。但你有没有想过——"他十指交叉，靠回椅背，"你面对的不只是我。"
他身后，玻璃幕墙外站着两个壮汉。不是助理。是保镖。
场景：会议室 / 过肩镜头看大屏
赵鹏按了个遥控器，会议室大屏亮了——
屏幕上是一个巨大的集团架构图。十几家子公司，触角伸向医疗、金融、AI、半导体。而我的公司，被标注在一个红色方框里——标签写着"待收购标的"。
这不是一个人的阴谋。这是一台机器。而我的公司只是它嘴里的一块肉。
◆ 决策点 D-4
赵鹏亮出终极底牌——背后是整个科技集团。怎么应对？
A. 硬刚到底 B. 假装投降，争取时间 C. 提出分拆合作方案
霹雳手段。示弱是最好的进攻。让他们以为赢了——然后在下一次循环中完成真正的布局。
场景：走廊 / 中景 / 顶光
两个保镖架着我的胳膊往外走。不算温柔，但也没真动粗——毕竟是在写字楼里。
没关系。这次是故意输的。我需要看到赵鹏的全部底牌。
场景：走廊 / 回眸特写 / 浅景深
被架到电梯口的时候，我扭头看了赵鹏一眼，淡淡说了一句：
"赵总——明天见。"
他当然不知道这句话的含义。
场景：会议室门口 / 赵鹏特写 / 冷蓝光
赵鹏站在会议室门口，看着我被带走。
他的表情从得意……慢慢变成了困惑。
那一瞬间，他一定感觉到了什么不对劲——一个输家不该有那种笑容。

07:00
场景：公寓 / 广角 / 蓝白屏幕光
最后三次循环。不再收集情报——开始布局。
四步棋。每一步必须在今天之内完成。
计划代号：「终局」。
第一步：转移核心代码到安全服务器。
第二步：联系赵鹏的竞争对手。
第三步：安排林薇母亲转院。
第四步：准备赵鹏的违法证据包。
场景：笔记本屏幕 / 特写 / 绿光
上午八点。核心AI源代码全量加密备份完成，传输到三个独立的安全节点。
就算他们拿到了旧版本，新版本的密钥只有我知道。
屏幕上显示绿色的"COMPLETE"。
第一步，完成。
场景：高级餐厅 / 中景 / 温暖优雅
上午十一点。CBD另一端，一家法式餐厅。
对面坐的是陈瑶——华远资本的合伙人。赵鹏在业内最大的竞争对手。
"陈总，我有一个提案，可能会让你非常感兴趣。"
我们握手的时候，她眼里闪过精明的光芒。
第二步，完成。
场景：夜晚天台 / 远景 / 青橙色调
下午一点。我联系了一个做医疗的老朋友。
"老周，帮个忙。今天下午三点，安排一辆救护车到盛安医院，转院手续我已经搞定了。"
林薇的母亲会在赵鹏发现之前离开他的控制范围。
林薇不会知道是我安排的。她只会收到医院的一个"正常转院通知"。
第三步，完成。
场景：书桌 / 特写 / 黎明微光
最后一块拼图。十次循环收集的所有证据——商业间谍、胁迫、关联交易、违规操作——全部整理成一份证据包。
三份拷贝。一份给律师，一份给陈瑶，一份……给媒体做备份。
第四步，完成。
该上最后一个存档了。
场景：穿衣镜前 / 中景 / 晨光切割
第十次循环的早晨。我站在镜子前，穿上了全黑的西装和黑衬衫。
不是丧服。是战袍。
镜子里的那个人，和第一次循环相比，眼神完全不一样了。
十条命的份量——全在这最后一次。
场景：办公大堂 / 低角度跟拍 / 自然光
走过大堂的时候，我注意到同事们下意识地让开了路。
也许是这身黑的气场。也许是我脸上的表情。
小陈小跑着跟上来：
"老板——赵鹏那边确认了，下午两点——"
"38层会议室，我知道。"
小陈又呆住了。
不好意思，这是第十遍了。
场景：会议室 / 广角 / 逆光镜头光晕
推开那扇我推过十次的玻璃门。
赵鹏在老位置，助理在老位置，保镖在老位置。一切都一样——
除了我。
我在赵鹏对面坐下，没有寒暄：
"赵总，今天我们不聊融资了。"
"聊聊你背后那位老板吧。"
场景：会议桌对面 / 双人特写 / 侧光
那一秒钟的空气，凝固了。
赵鹏的表情从例行公事的优越，一帧一帧地切换成——
震惊。
他知道了。我什么都知道了。
十次循环。十条命。换来的就是你脸上这个表情。
值了。
场景：赵鹏 / 极端特写 / 底光阴影
赵鹏的面具碎了。
五十岁的老江湖，第一次在谈判桌上额头冒汗。
"你……怎么会知道……"
因为我已经活了十遍今天，赵总。你不知道而已。
场景：会议室 / 俯瞰 / 电影式顶拍
我站起来，双手撑在桌面上，环顾四周。
赵鹏的助理不安地看向赵鹏。保镖没有接到指令，不敢动。
"证据包已经在律师手里了。转院手续办完了。你的竞争对手——陈瑶，刚才和我吃了个早饭。"
"赵总，这局棋……该你落子了。"
场景：手机特写 / 浅景深 / 戏剧停顿
就在这一刻——
桌上的手机震了一下。
匿名号码。一条消息。
场景：朱江侧脸 / 电影级特写 / 明暗分割
我低头看了一眼——
「你以为你是唯一一个在循环的人吗？」
我的笑容，凝固了。
