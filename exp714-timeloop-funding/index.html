时间循环

融资死局

第一章 · 无限路演日
↓ 向下滑动开始 ↓
LOOP 01
第一次循环
闹钟响了。七点整。
我的手条件反射般拍过去，闹铃声戛然而止。床头柜上散了一堆融资计划书——昨晚改到凌晨三点的"梦境科技A轮融资方案V27"。
坐在床边揉了揉眼，脑袋像灌了水泥。今天是路演日，如果搞砸了，梦境科技账上只够撑两个月。
两个月。六十天。算上泡面，也许能撑到七十天。
洗把脸，镜子里的我看起来像个连续加班一周的程序员——哦等等，我本来就是。
镜子里这张脸，今天要靠它打动一个据说从不笑的投资人。
最后过一遍PPT。每张都背得滚瓜烂熟——"AI短剧将重新定义内容消费"，"千人千面的故事引擎"，"用户留存率89%"。
数据完美。逻辑无懈可击。如果投资人是机器人的话，这轮融资已经到账了。
陆家嘴，鼎丰大厦。玻璃幕墙映着上海的天际线。我整了整深蓝西装的领口——没打领带，第三颗扣子开着，这是我的小叛逆。
创业者嘛，西装是尊重，不打领带是态度。
会议室。投影屏亮起。对面坐着三个人。

中间那位——陆薇薇，鼎丰资本合伙人。短发，黑色职业套装，表情像是刚从冰箱里拿出来的。
据说她上一次笑，是三年前某个项目上市当天。此后再无记录。
我进入了状态。手势精准，声音稳定，每一页PPT的切换都卡在节奏点上。

"梦境科技的AI引擎，可以为每个用户生成专属的短剧故事——"
说得好。完美。就像在CodeReview里写了一段零警告的代码。
陆薇薇全程抱着胳膊，面部肌肉零活动。就好像我面前坐着一尊高定西装的冰雕。

她旁边两个同事偶尔低头看手机。
这感觉就像……在一个空旷的剧场里，给三块石头做TED演讲。
被拒了。意料之中，又在意料之外。

我坐在沙发上，双手捂着脸。电脑屏幕上亮着那封措辞礼貌到刺眼的拒绝邮件："经过审慎评估，目前暂不适合我们的投资方向……"
翻译成人话：你的PPT讲得不错，但我们不感兴趣。
今天的表现，0分。投资人的表情，像在审阅一个我自己都不想看的代码Review。
十一点五十九分。

我躺在床上盯着天花板，脑子里还在复盘每一个细节。哪里出了问题？数据没问题，逻辑没问题，PPT没问题——

视线模糊了。房间开始泛白。
好困。明天再想吧……
LOOP 02
第二次循环
闹钟响了。七点整。

我的手伸过去——然后停住了。
等等。这个闹铃声。这个角度。床头柜上的融资计划书。
V27。
不是V28。
不是V28。
手机日期：3月15日。

昨天也是3月15日。

我的脸从困惑变成……
[DECISION-1] 发现自己在时间循环中
A：恐慌——"这是什么鬼？我疯了？"
→ 花大量时间验证、打电话确认、怀疑人生
B：兴奋——"免费重来？这不就是无限存档点？"
→ 立刻利用这个机会
创业者最不怕的就是从头再来。
黑客遇到bug的第一反应不是恐慌，是利用。
我从床上跳起来，在客厅里张开双臂大笑。

"哈哈哈哈！无限存档点！SL大法！"
别的创业者花钱买教训，我直接开了免费重来的外挂。陆薇薇，今天我要把你这道题做对。
同一间会议室。同样的三个人。我讲到第八页PPT的时候——

陆薇薇的眼神开始飘了。和昨天一模一样。
[DECISION-2] PPT讲到一半，效果不行
A：硬着头皮讲完——"专业就是把烂牌打完"
B：合上电脑即兴发挥——"反正明天重来，不如测试一下"
代码跑不通就别硬调，重构。
菩萨心肠，霹雳手段。
我"啪"一声合上笔记本，站起来，双手插兜，微微一笑。

"PPT太无聊了，陆总。咱们聊点真的？"

老刘在旁边差点从椅子上掉下来。
老刘的表情堪称今日最佳——嘴张成了一个标准的O型。
然后我开始即兴演讲。

讲AI如何改变世界。讲得激情澎湃，讲得热血沸腾。

讲到"AI将改变每一个人的命运"的时候，老刘打了个哈欠。
对面三个投资人同时看了眼手表。完美同步，建议组团表演。
好的。即兴演讲也不行。比PPT还差。

不过没关系，这就是测试。A方案失败，B方案失败，记录下来，明天再试C方案。
今天又被拒了。但这次我一点都不沮丧。
不过——

我注意到一个细节。

在我讲到某句话的时候，陆薇薇的表情变了。非常非常微小的变化。一般人根本不会注意到。
但我是写过人脸识别算法的人。我对微表情的敏感度，大概相当于一台分辨率还不错的摄像头。
她的眼睛——闪了一下。

极其短暂。大概零点三秒。

这堵防火墙……有端口。
只要我扫得够仔细。
当晚。我坐在电脑前，把今天的每一秒都在脑子里回放。

我说了什么的时候，她眼睛闪了？

想不起来了。太快了。
没关系。明天我会盯得更仔细。
明天，一定会再来一次。
LOOP 03
第三次循环
七点。闹钟。

这次我平静地拿起闹钟，关掉，放好。
第三轮。这次不是试错，是精准打击。
我花了一个小时在纸上画投资人行为图谱。

循环1：陆薇薇在第8页开始走神，第12页完全放空。
循环2：即兴演讲让她更早走神，但某句话触发了0.3秒的眼部反应。

如果这是一段代码，我要找的是那个触发break条件的变量。它藏在某句话里。
同一间会议室。第三次。

这次我没讲PPT，也没即兴发挥。我坐下来，双手撑在桌上，看着陆薇薇的方向——

"陆总，我不讲数据了。我讲一个用户的故事。"

老刘在旁边紧张得直搓手。
"去年冬天，我们做了一个测试。把AI短剧推送给了一个贵州山区的养老院。有个78岁的老太太，儿子在深圳打工三年没回家。"

"我们的AI给她生成了一个故事——一个在大城市工作的儿子，每天都在想妈妈，终于决定回家过年。"

"她看完以后，哭了。然后给儿子打了个电话。那是三年来的第一个电话。"
陆薇薇的笔停了。

就是这个瞬间。

笔尖悬在半空，手指微微收紧。
上一次循环那0.3秒的眼部闪动，这次变成了整整一秒的手部停顿。

我找到端口了。
我的眼睛飞速扫过她的手，又移回她的脸。

变量名：sincerity。
类型：boolean → 不，不是boolean。是float。有程度的。
上一次循环我触发了0.3的阈值，这次触发了更高的值。但还没到break的条件。
但今天还是被拒了。

不过拒绝邮件的措辞……变了。从"暂不适合"变成了"希望保持联系"。
走出会议室的时候，我没有崩溃，没有兴奋。只是在想。

老刘小声问："怎么样？"

"还差一点。"我说，"但我知道方向了。"

如果明天还能重来，我就能破局。
如果。
深夜。我打开电脑准备整理今天的复盘笔记。

屏幕上弹出一个窗口。

不是我打开的。

绿色代码在黑色背景上闪烁——
while(true) {
  if(sincerity > threshold)
    break;
}

我的瞳孔里映着绿色的代码光。

sincerity > threshold。
真诚度超过阈值才能break。

谁写的这段代码？
谁知道我在循环里？
谁——在看着我？
[DECISION-3] 发现电脑上的神秘代码
A：先不管来源，利用线索破局——"先把融资搞定再说"
B：追查代码来源——"谁动了我的系统？"
黑客天性——谁动了我的系统，这才是最重要的问题。
融资可以明天再试，但这个线索，可能不会再出现。
窗外是上海的夜。千万盏灯，千万个故事。

而在这些灯火中，只有一扇窗户里的人，正在经历一个不属于这个时间线的夜晚。

有人也在循环里。
而他，知道我在。
有人也在循环里。
循环的代码是谁写的？
sincerity的threshold到底是多少？
还有谁……也困在这一天？
