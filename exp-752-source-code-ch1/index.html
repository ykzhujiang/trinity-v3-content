第一幕 · 蓝屏重启
BLUE SCREEN REBOOT
凌晨三点十七分。我已经在这把椅子上坐了十四个小时。
屏幕突然蓝了。满屏代码像瀑布一样往下刷——这不是普通的蓝屏。
桌上全是战斗的痕迹：三杯咖啡、两盒外卖、一沓写满算法的草稿纸。我揉了揉眼睛，准备重启。
然后——头炸了。不是比喻。真的像有什么东西在颅骨里面爆开。
等疼痛过去，我睁开眼。世界……变了。空气中飘浮着半透明的绿色代码流，像数据粒子在呼吸。
我看向自己的手——上面浮现出一排参数：心率92、肾上腺素↑、疲劳度87%。就像游戏里的状态面板，但这是真的。
……我是不是加班加出幻觉了？
走到窗边。城市夜景还在，但每栋楼之间多了发光的数据高速公路。信息像血液一样在城市的血管里流动。壮观得让人窒息。
第二幕 · 新世界
NEW WORLD
第二天早上。我洗脸的时候看了一眼镜子——头顶飘着属性面板：CEO · Lv3 · 精力42% · 压力78%。
好家伙，一夜没睡，精力都红了。
走进公司，前台小姐姐头上飘着：开心62% · 暗恋某人 · 今天想请假。
……这信息量也太大了。
晨会。每个同事头上都有参数，五颜六色的浮标在会议室里飘来飘去。林小鱼的面板最扎眼：焦虑71% · 核心事件：服务器bug未修复。
我："小鱼，昨晚服务器是不是出了问题？"
林小鱼："你怎么知道？！我还没说——"
这玩意……比任何数据分析工具都强。而且不要钱。
下午要和竞品公司开商业合作会。我换上了西装外套，在镜子前整理了一下。
该上战场了。
会议室里，对面坐着竞品的张总，笑容满面。但他的代码全是红色警告——紧张89% · 核心意图：拖延合作窃取技术方案 · 谎言计数：3。
好家伙。笑得越灿烂，代码越血红。
张总："朱总，我们非常期待这次合作！"
他头顶弹出实时解析：谎言#4 · 真实意图：获取核心算法后单方面终止。
▶ 决策点 1
发现谎言。拆穿？隐忍？警告？
→ 我选择隐忍。先收集证据，再精准打击。——菩萨心肠，霹雳手段。
我："张总说得好，我让团队准备详细方案。"
手在桌下悄悄用手机拍下了他的"代码快照"。
我："合作方案先别发，我有新情报。"
林小鱼："什么情报？"
我："直觉。"
（其实是开挂。）
第三幕 · 过载
OVERLOAD
晚上回到家，我开始测试这个能力的边界。电视里新闻主播在播报——她的代码显示：提词器模式，紧张度45%。
连新闻都能看穿……这东西到底是什么？
窗外的世界更壮观。楼下每个路人都是流动的数据包，整条街像一条数字河流。
我试着"聚焦"一个外卖小哥——信息放大了：收入日均280 · 今日订单23 · 疲劳97% · 内心：想女儿。
……能看到别人的内心，这种能力，到底是福是祸？
然后——鼻血来了。一滴血落在白T恤上。
操。
视野开始模糊，代码流变成乱码。头痛炸裂。我扶着墙，整个世界在抖。
代码视觉强制关闭了。世界恢复"正常"。我坐在地上喘气，像刚跑完马拉松。
▶ 决策点 2
能力过载，第一次流鼻血。恐惧？兴奋？冷静分析？
→ 我选择冷静分析。每个系统都有规则。规则能被逆向，就能被优化。
我擦掉鼻血，翻开笔记本开始记录：触发条件：聚焦深度 · 持续时间≈28分钟 · 过载症状：鼻血+视觉模糊 · 恢复时间：待测。
每个系统都有规则。规则能被逆向，就能被优化。——这是黑客的本能。
我给这个能力取了个名字。像创业者给产品命名一样，我在笔记本上写下两个字：
「代码之眼」
深夜。我在电脑前写了一个简单的自测程序：每天记录代码之眼的使用时间和症状。用debug的方式debug自己——这大概是全世界最疯狂的自测了。
第四幕 · 暗线
HIDDEN THREAD
第三天。我穿上最好的西装走进会议室。证据已经收集够了，是时候收网了。
当着双方律师的面，我"不经意"地提到了几个技术细节——每一个都是从张总的代码里读出来的真实意图。张总的脸一秒比一秒白。
合作终止。张总灰溜溜地走了。
林小鱼："你到底怎么知道这些的？"
我："做了功课。"
（年度最佳轻描淡写。）
当晚，我请全公司吃火锅庆功。锅底翻滚，笑声不断。在这个能看穿一切的新世界里，最真实的东西，还是一顿热气腾腾的火锅。
回家路上。我无意间扫了一眼路人——代码正常。出租车司机——代码正常。一切都很平常。
然后——一个穿黑色卫衣的人走过。我习惯性地扫过去——
那个人没有代码。整个人是一片空白。像一段被注释掉的代码。
我停下脚步，回头看。那个人也停下了。没有回头。但他头顶缓缓浮出一行字——
「你也看得见？」
夜色无声。两个人背对而立。
空气中只剩这一行代码。
