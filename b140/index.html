第一章：醒在2005
重生 科技 创业 2005
【俯拍·缓推】凌晨3:30的科技公司办公室，只有一盏台灯亮着

我的意识在一片代码的海洋里挣扎……又是一个通宵。这个该死的bug改了整整一天，还是跑不通。

手边第四杯美式已经见底，胃在抗议，眼皮在打架。
【特写·电脑屏幕】显示器上密密麻麻的代码和AI训练面板

明天……不，今天下午就要给投资人演示了。这个模型要是调不通，这一轮融资就黄了。

便签上潦草地写着：明天投资人演示
【侧面·急拍】突然胸口一紧，眼前一黑——

“不……不是现在……”

咖啡杯被撞翻，棕色液体在桌面蔓延。我感觉自己在往一个无底的黑洞里坠落……
【黑场·转场】

一片虚无。

意识像断线的网络连接，在黑暗中漂浮。不知道过了多久——也许是几秒，也许是一辈子。

然后，我听到了一个声音……
【仰拍·第一视角】从床上往上看到的天花板

……姚明的海报？周杰伦的演唱会海报？？

这个天花板……这个霉味……这铁架床的吱呀声……

不对。这是——
【中景·侧面】猛地坐起来，头差点撞到天花板

“我靠——！！”

我盯着自己的手——光滑的、没有老茧的、22岁的手。摸了摸下巴——光溜溜的，胡子呢？！
【特写·翻盖手机】银色诺基亚翻盖手机屏幕

2005年6月29日。星期三。

二零零五年。

我的手在发抖。
【过肩镜头·镜子】看着镜子里22岁的自己

镜子里是一张年轻得不像话的脸。没有黑眼圈，没有法令纹，没有那把标志性的络腮胡。

“我……重生了？？”

心跳快得像要炸开。20年。我回到了20年前。
【中景·3/4侧】室友小王在打CS 1.6

“操！又被AWP爆头了！”

小王穿着湖人球衣，对着CRT显示器猛敲键盘。他完全没注意到我刚才差点从上铺摔下来。

Windows XP的开机音乐从隔壁宿舍传来。一切都这么……真实。
【中景·双人】朱江激动地比划，小王一脸懵逼

“小王你听说过大语言模型吗？就是那种能跟你对话的AI——”

“什么玩意？新的CS地图？”

“不是！就是……算了。那你知道短视频吗？就是15秒的——”

“15秒能拍什么？你发烧了吧？”
【近景·微仰拍】坐在上铺边缘，望向窗外的校园

脑海里像放电影一样——

iPhone，2007年。安卓，2008年。微信，2011年。比特币从几分钱涨到几万美元。短视频颠覆一切。然后是AI大模型……

这些我都知道。我全都知道。

问题是——我该怎么用这些知识？
【特写·静物】宿舍桌面的2005年时光切片

日历：2005年6月。报纸头条：中国互联网用户突破1亿。

1亿……20年后这个数字会变成10亿。而我知道每一步是怎么发生的。

我拿起那份报纸，手指微微发抖。这不是博物馆的展品，这是今天的新闻。
【中景】小王转过身来，一脸好奇

“对了老朱，你想好没？毕业去华为还是去那个……叫什么来着，那个小公司？你导师推荐的。”

那个“小公司”。

我当然知道它是什么——三年后它会成为移动互联网巨头，五年后纳斯达克上市，市值百亿美金。
【特写·分屏意象】内心的挣扎与权衡

选项A：去华为，稳稳当当，月薪8000，在2005年算高薪了。

选项B：拒掉所有offer，从零开始创业。22岁，零资源，零人脉。

选项C：先去那家小公司，积累两年资源再出来。

上辈子的我选了C。结果呢？等我想出来的时候，最好的时机已经过了。
【中景·站立】猛地站起来，眼神坚定

“都不去。”

“啊？”

“我要自己干。”

小王的嘴巴张成了O型。但我心里无比清楚——我不是22岁的愤头青。我脑子里装睂20年的未来，我知道每一个风口在哪里。

这一次，我不会再错过。
【特写·反应镜头】小王震惊脸

“你疑了吧？！放着华为不去？你爸妈不得把你腿打断？”

“两年后你会感谢我拉你入伙的。”

“……你今天真的没发烧？”
【远景·校园】走在交大的林荫道上

夏天的交大校园。梧桐树的影子斑驳地洒在地上，有人骑着永久牌自行车经过，远处传来食堂阿姨“最后一份红烧肉”的吼喌声。

一切都那么熟悉，又那么遥远。

我深吸一口气——这是2005年的空气，干净得让人想哭。
【街景】2005年的网吧

蓝星网吧。五块钱一小时。

我需要一台能上网的电脑。宿舍那台奔腾III太慢了，我需要做的事情很多——

注册域名，搜集市场数据，写商业计划书。

我推开了那扇烟雾缭绕的门。
【网吧内景】坐在电脑前，打开百度

屏幕分辨率800×600。百度搜索的页面简洁得可怕——没有推荐信息流，没有短视频，就是一个搜索框。

我敲下第一个搜索词：“手机游戏 Java 开发”

2005年，智能手机还是诺基亚和摩托罗拉的天下。iPhone还要两年才发布。现在最火的是Java手游——贪吃蛇、推箱子。

但我知道一个秘密：手游市场即将爆发。
【特写·思考】网吧蓝光映照的脸

三个方向在脑海里碰撞——

A：手机游戏。2005年最成熟的移动变现路径。

B：移动社交。做一个类似微信的产品。这才是终极答案……但2005年做社交？没有智能手机，没有3G网络，用户基础为零。死路一条。

C：电商导购。移动互联网的入口。但流量从哪来？
【意象画面】三条路在眼前展开

上辈子的经验告诉我：你不可能一步登天。

雷军说过“顺势而为”——但更关键的是，在势来之前你得先活着。

社交是2011年的事。现在是2005年。我得先赚到第一桶金。
【中景】开始写商业计划书

手游。就是手游。

不是因为它最赚钱，而是因为——

第一，2005年Java手游有成熟的分发渠道（移动梦网）。
第二，开发成本低，两三个人就能做。
第三，能快速验证我的商业能力。

“菩萨心肠，霸雳手段。”我在心里默念。先务实，再理想。
【特写·键盘和屏幕】飞速敲击的商业计划

市场分析：2005年中国手机用户3.9亿，Java手游下载量月增40%……

竞品分析：当前市场以休闲益智为主，缺少故事驱动型游戏……

盈利模式：移动梦网分成 + 预装合作……

这些数据，别人要花三个月调研。我只需要从记忆里掏出来。
【中景】小王来到网吧找我

“我靠，你真的在写商业计划书？我以为你开玩笑的……”

小王递给我一瓶康师傅绿茶——两块钱，2005年的物价让我差点哭出来。

“我从来没这么认真过。”

“你这上面写的数据……你怎么知道的？”

“直觉。”
【双人·喜剧】又一次穿越者暴露

“这个产品的核心逻辑就是——做私域流量的转化，用内容种草带动用户增长——”

“……你在说中文吗？”

我愞了一秒。对。2005年没有“私域流量”这个词。甚至“用户增长”都还不是通用术语。

“咳……就是，让人知道我们，然后来买东西。”

“那你直接这么说不就行了？”
【远景·黄昏校园】夕阳下的两个年轻人

我花了整整一个下午给小王画饼。

不，不是画饼。每一个“饼”我都知道它会实现。我只是还不能告诉他原因。

“你真觉得手机上玩游戏能赚钱？”

“两年之内，手机游戏会是一个百亿市场。”

“百亿？你在做梦吧。”

“信不信由你，反正我信了。”
【宿舍夜景】在笔记本上画未来的蓝图

夜里十一点，宿舍熄灯了。我打着台灯在笔记本上画路线图——

2005：手游公司启动，Java游戏，赚第一桶金
2007：iPhone发布，立刻转iOS开发
2009：移动互联网爆发，做社交产品
2011：微信出现……不，我要抢在它前面

写到这里我停下了笔。

我能改变历史吗？还是历史会改变我？
【特写·新闻页面】那条改变世界的新闻

第二天下午，网吧里。

我习惯性地刷科技新闻——然后，我看到了那条消息。

“谷歌收购安卓公司，收购价5000万美元。”

别人看到这条新闻的反应：哦，又一个小收购。

我的反应——
【特写·表情】看到新闻的瞬间

安卓。

那个将来会装在全球30亿台设备上的操作系统。此刻，它只值5000万美元。而我知道它的未来。

心跳加速到150。

不是因为恐惧。是因为——我看到了一个改变命运的入口。
【极特写·拳头】紧握的拳头

一个疑狂的念头在脑海中成型——

如果……我能在安卓生态建立之前，就占据一个关键位置呢？

不是做安卓本身——那是谷歌的事。

而是做安卓生态上的第一批应用。第一批游戏。第一批开发者工具。

当所有人还在用翻盖手机的时候，我已经知道触屏时代要来了。
【仰拍·英雄镜头】站起来的那一刻

我站了起来。

2005年的中国互联网，还是一片蛮荒。百度刚上市，阿里还在做B2B，腾讯的QQ空间刚刚起步。

而我，一个22岁的大学毕业生——不，一个装睂20年未来记忆的灵魂——

我要在这片蛮荒中，建一座帝国。
【俯拍·笔记本】疑狂计划的雏形

那天晚上，我在笔记本上写下了一个计划。

一个只有“来自2026年的人”才敢写的计划。

——
